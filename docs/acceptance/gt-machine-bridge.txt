## 2. GameTest（`.\gradlew.bat runGameTestServer`）

```
All 40 required tests passed :)
```

新增 `GtsnMachineBridgeGameTests`（2 项）：

- `snapshotReadsPlacedGtMachine`：在结构内放置 `gtsnlib:test_machine`，经 `GtMachineSnapshots.at` 取快照，
  断言精确机器 id = `gtsnlib:test_machine`、tier = 1、容量 = 2048、输入电压 = 32；无配方逻辑机器
  `status == UNKNOWN`、进度 = 0；再经 `GtMachineDebug.charge` 服务端注入 512 EU，断言
  `energyStored() == 512`（可失败；注入关闭时该断言 RED，见 `review-24-fixes.txt` §2）。
- `snapshotAbsentForNonMachineBlock`：石头方块不产生快照、不被判定为 GT 机器，且 `charge` 返回 0。

> 断言纪律修正（#24 F1-2）：旧版 `energyStored()>=0` / `inputVoltage()>=0` / `status` 非空等断言因
> `GtMachineSnapshot` 钳制与 status 归一而永不失败；现改为上述精确 / 注入后可失败断言。
